# PPS Enumerations & Typedef Engine

A Semester 1 Programming for Problem Solving (PPS) C application demonstrating named integer constants using `enum` and custom type definitions using `typedef`.

## PPS Concepts Covered
* **Enumerated Types (`enum`)**: Defining readable, self-documenting symbolic constants for integer states.
* **Type Aliasing (`typedef`)**: Simplifying complex type declarations for code readability.
* **Enum Switch Dispatching**: Controlling program branching using named enumeration states.
* **Status Codes**: Utilizing enums as expressive return codes for function validation routines.

## How to Compile & Run
```bash
gcc main.c -o enums_typedef
./enums_typedef
